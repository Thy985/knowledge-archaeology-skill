# ADR-0001 · Authority Separation（判断力与执行权分离）

- **状态**：Accepted（2026-01-15）
- **核心问题**：Agent 的分析结论（判断）能否直接驱动系统执行？

## 背景

v0 里 Agent 直接调用 executor 执行命令。一次 `rm` 误判导致数据丢失后，发现：
"AI 判断可靠"是错误假设——判断可能有错，而一个错误判断 = 一次未授权变更。

## 决策

Agent 只产出**意图（intent）**；执行权移交给 `PermissionGate`（三态审批）+ `Guardian`（fail-closed）。
意图 → 审批 → 执行 三段分离，任何一步都可由人类介入。

## 被放弃的方案

- **方案 A：让 Agent 自证安全后自执行** —— 放弃：自我证明不构成独立验证（line 9 论证）
- **方案 B：黑名单只挡已知危险** —— 放弃：未知危险（fail-open）比已知危险更致命

## 后果

- 好处：即使 AI 全错，系统仍可控、可验证、可恢复
- 代价：多一跳审批延迟；需要策略固化机制避免每次都要人工确认
